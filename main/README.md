# Main Problem submission package

`REPORT.md` is the existing Main Problem report, with relative evidence links to the canonical `M/` records and local snapshots in `results/`. It reports the original nine-test battery as blocked and keeps supplementary registered and exploratory evidence separate. `code/M/` contains copies of the tracked Main Problem Python sources. `configs/` contains copies of the frozen configuration, schemas, preregistration, and evaluator contract. `results/` contains result snapshots; the hashes cited in `REPORT.md` were checked against the canonical records.

The canonical runnable package and complete source-bound evidence remain in `M/`. Run documented read-only reproduction commands from the repository root. These packaging copies do not represent additional experiments or alter the originals.
