# Official scope retained for the first implementation

Source: ASI Intern Recruitment 2026, PDF pages 42–46, read completely.
Requirements: one shared Φ(q,R,t), cheap readout, published/generated settings,
retrieval with provenance if inputs absent; I identity/signed scope, N several
strictly prior coordinates, G grounding/support/copy/answeredness, two Q factors,
D per facet with E5 tests, T historical updates. Baselines B-Q/B-ABS/B-TF/B-LEN;
optional B-JUDGE. Empty/shuffled-input and same-topic-decoy controls.

Train through 2023, select on 2024, gap until July 2025, hash/commit the test list
before opening it. Every claimed improvement needs its preregistered paired
95% interval and margin; authorship/length/topic/system effects must be separated.

Core battery: I1 paraphrase, I3 length matching, S1 near-miss, A1 novelty axioms,
H1 expert battles raw and system-demeaned, H3 post-cutoff review scores/ceiling,
O1 both post-cutoff quality factors, O2 same inputs, T1 training-year invariance.
Extended: I2 authorship, I4 order/format, S2 facet edits, S3 time, H2 reviewer
novelty beyond quality, H4 facet overlap, O3 already-asked generated questions,
K1 within-topic quality clustering, T2 re-asking forecasts, R1 retrieval regression.

Rubric: design 15, battery 25, results 20, insight 20, reproducibility/reuse 10,
integrity 10. This code makes no claim to those marks, a completed battery or
held-out performance. The user requested the first working implementation only.
