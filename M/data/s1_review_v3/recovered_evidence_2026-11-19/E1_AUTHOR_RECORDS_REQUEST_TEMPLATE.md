# Request for original E1 records — S1 questions

Please provide existing contemporaneous records only. Do not reconstruct dates or controls from memory. If a record was never made or cannot be found, please state that explicitly.

For each of the 61 E1 question IDs (h001–h062, excluding h028), please provide:

1. The exact question text/version as it existed at the time, including a stable version identifier or original file/export.
2. The actual creation/posing date and time, and the contemporaneous record that establishes it.
3. The actual sharing/availability date and time for that exact version, and the email/platform/archive record that establishes it.
4. The exact original input paper list supplied for that question. For every paper, include the original ID, exact version, SHA-256 of the supplied bytes, and evidence the version was available at the relevant time.
5. The original records for each registered condition: original inputs, empty inputs, cross-instance shuffled inputs, and same-topic unsupported decoy. Include source-instance/question IDs, paper IDs and versions, exact record/payload files, and hashes.
6. For each same-topic decoy, the original independent verification record establishing both same-topic relevance and lack of support for the target claim.

## How to return the evidence

- Preserve original files and metadata; do not rewrite or normalize them.
- Include the original storage location or platform/export context and the file SHA-256.
- Identify the question IDs covered by each file.
- Distinguish a record created at the time from a later recollection or reconstruction.
- If only a partial record survives, identify precisely what it does and does not establish.
- Please separately identify any records that never existed.

The existing collection spreadsheets to populate after evidence is received are `E1_QUESTION_HISTORY.csv`, `E1_PAPER_INPUTS.csv`, and `E1_S1_CONTROLS.csv` in this directory. These are inventories, not substitutes for source evidence.
