# Retrospective first-publication source review form

This is an uncompleted form for a genuine human source review of the 299
benchmark papers. Its metadata columns were copied from the existing local
review record. Blank reviewer fields are intentionally blank; do not infer a
first publication date from the 2025-10-08 OpenReview release, venue year,
forum ID, arXiv identifier, or a missing search result.

For each row, the reviewer should record their initials and review date; a
primary source URL and exact locator supporting paper/version identity; the
earliest publicly verifiable version date and the source that establishes it;
whether an earlier preprint exists; and an evidence-based identity/eligibility
decision. Prefer the paper's authoritative repository version history or
publisher record, and preserve the exact version matching the benchmark's
original abstract. If the evidence is unavailable or conflicting, mark the row
unresolved and explain why. Do not guess or backdate a review.

This is publication-provenance review, not a request to create novelty labels
or independent ratings. It cannot establish the encoder's unknown training
cutoff. Any review performed now is retrospective and must be reported as such.
