# Prospective nearest-paper planting extension

Use the original 241 count-eligible and cache-eligible focal papers with the 964 conditions in cached_extensions_v1/nearest_planting_plan.jsonl. Freeze the file identities below before the first planting embedding. For each plan, encode only the synthetic title plus abstract in the 1,304-request inventory using the frozen CPU proximity encoder. Apply its three cached controls after each model initialization. Store normalized float32 vectors in analysis/nearest_planting_vectors_v1/modified_papers.sqlite3. Restart from validated saved rows.

For each focal compute one paired baseline by undoing the plan's synthetic replacements in the original pool order. Compute Y, N, yours and relative neighbour density with cached_extensions.calculate on the baseline and each planned 25%, 50%, 75% and 100% replacement pool. Retain per-paper measurements, all 241 denominators and all ties. For descriptive comparisons count a non-increase if the higher-coverage score minus the lower-coverage score is at most 1e-8, including ties. Report versus baseline and successive coverage levels. These development results extend the prior inspected experiment. The previous 52-paper N/yours extension uses different pools.

Host execution requires a separate planting-only invocation. The vector worker checks host processes, memory, disk, model files and frozen sources. It uses the existing low-priority CPU loader. The explicit scoring option takes the finished planting database checksum. Printing inventory uses no inference. This scope does not authorize any held-out experiment.
