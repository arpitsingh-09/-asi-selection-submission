# T5 — The Value of a Question

## T5.A — Computing Value

### Task A.1 — Derive the mutual information formula

Let the hidden hypothesis be (H\in{0,1}), with prior probability:

\[
P(H=1)=\pi,\qquad P(H=0)=1-\pi
\]

The binary measurement outcome (Y) satisfies:

\[
P(Y=1\mid H=1)=a
\]

\[
P(Y=1\mid H=0)=b
\]

Using the law of total probability:

\[
P(Y=1)=\pi a+(1-\pi)b
\]

Since (Y) is binary, its entropy is:

\[
H(Y)=h(\pi a+(1-\pi)b)
\]

where:

\[
h(p)=-p\log_2p-(1-p)\log_2(1-p)
\]

The conditional entropy is:

\[
H(Y\mid H)=\pi h(a)+(1-\pi)h(b)
\]

Mutual information is defined as:

\[
I(H;Y)=H(Y)-H(Y\mid H)
\]

Therefore, the information value of question (q) is:

\[
\boxed{
v(q)=h(\pi a+(1-\pi)b)-\pi h(a)-(1-\pi)h(b)
}
\]

This measures how much observing the outcome reduces uncertainty about the hidden hypothesis.

### Task A.3 — Prove the upper bound and interpret Q2 and Q3

Mutual information can be expressed as:

\[
I(H;Y)=H(H)-H(H\mid Y)
\]

Since conditional entropy is non-negative:

\[
I(H;Y)\leq H(H)
\]

Similarly:

\[
I(H;Y)=H(Y)-H(Y\mid H)
\]

Therefore:

\[
I(H;Y)\leq H(Y)
\]

Combining both inequalities:

\[
\boxed{v(q)\leq\min{H(H),H(Y)}}
\]

Interpretation of Q2 — Unpredictable but uninformative

Q2 has maximum outcome entropy:

\[
H(Y)=1\text{ bit}
\]

However, its conditional probabilities are identical under both hypotheses:

\[
P(Y=1\mid H=1)=P(Y=1\mid H=0)=0.5
\]

The outcome is independent of the hidden hypothesis. Therefore, observing it provides no information about (H):

\[
v(Q2)=0
\]

Thus, unpredictability alone does not make a question valuable.

Interpretation of Q3 — Already almost answered

For Q3, the prior probability of (H=1) is already 0.99. The existing prior knowledge strongly favours one hypothesis before conducting the measurement.

Consequently, the measurement provides little additional information:

\[
v(Q3)\approx0.025\text{ bits}
\]

Thus, a question can have a reasonably discriminative measurement but little value when the answer is already strongly indicated by existing knowledge.

The central distinction is that surprise and information value are not equivalent.

## T5.B — From the Toy World to Texts

### Task B.1 — Embedding distance versus information value

Embedding distance measures textual or semantic separation from existing reports. Information value measures how much a measurement reduces uncertainty about competing hypotheses. These quantities need not have the same ranking.

Consider two questions with the same prior:

\[
\pi=0.5
\]

Question Q-A — Informative measurement

Wording:

“Does the proposed intervention produce different outcome distributions under competing hypotheses about the underlying mechanism?”

Parameters:

\[
a=0.9,\quad b=0.1,\quad\pi=0.5
\]

Its information value is:

\[
v(Q_A)=h(0.5)-h(0.9)=0.531\text{ bits}
\]

Suppose its embedding distance from existing reports is 0.05.

Question Q-B — Uninformative measurement

Wording:

“How does a quantum-inspired framework transform the ecological dynamics of distributed systems?”

Parameters:

\[
a=0.5,\quad b=0.5,\quad\pi=0.5
\]

Its information value is:

\[
v(Q_B)=h(0.5)-h(0.5)=0
\]

Suppose its embedding distance from existing reports is 0.80.

The distances are illustrative values used to construct the counterexample, not measured experimental results.

Question	Embedding distance	Information value
Q-A	0.05	0.531 bits
Q-B	0.80	0.000 bits

An embedding-distance metric ranks Q-B as more novel, whereas information theory ranks Q-A as more valuable.

Why can the rankings disagree?

Embedding distance depends on the representation of the question’s wording relative to existing reports. Mutual information depends on the prior distribution of hypotheses and the conditional outcome distributions of the proposed measurement.

The wording can change without changing the underlying measurement mechanism. Conversely, two questions with similar wording can describe measurements with very different information values.

Therefore, no general mathematical relationship forces embedding distance and information value to produce the same ranking. A question can be textually distant but scientifically uninformative, or textually similar but highly informative.

### Task B.2 — Evaluation for detecting shortcut learning

Suppose a model predicts information value (v) using existing reports (R) and a research question (q).

The evaluation should determine whether the model genuinely uses the reports and understands the measurement mechanism, rather than relying on superficial textual patterns.

Test 1 — Report-hiding control

Procedure:

* Evaluate the full model using both existing reports and the research question.
* Evaluate a control model with the reports hidden.
* Keep the questions, labels and evaluation split unchanged.
* Compare prediction performance using MAE and (R^2).

Expected result:

If the reports provide useful evidence, the full model should outperform the report-hidden control. Similar performance would suggest that the model may be ignoring the reports and relying mainly on question wording.

Test 2 — Identical question with different reports

Procedure:

* Construct pairs of examples containing exactly the same question text.
* Associate each instance with a different set of existing reports.
* Select report sets that genuinely change the prior beliefs or evidence relevant to the hypotheses.
* Recompute the reference information values for both contexts.
* Compare the model’s predictions.

Expected result:

The predictions should change when the reports change if the reports alter the information available about the hypotheses.

If the model produces nearly identical predictions despite meaningful changes in the evidence context, it may be relying on question text rather than the reports.

Test 3 — Unseen measurement mechanisms

Procedure:

* Group questions by their measurement-mechanism families.
* Train the model using selected mechanism families.
* Hold out entire mechanism families during training.
* Evaluate the model on questions involving the unseen mechanisms.

Expected result:

A model that has learned the underlying relationship between hypotheses, measurements and outcomes should generalise to unfamiliar measurement mechanisms.

A substantial performance decline would suggest that the model has memorised familiar wording or mechanism-specific patterns instead of learning the underlying concept of information value.

Summary of shortcut tests

Test	What it detects
Report-hiding control	Whether predictions depend on existing reports
Identical question, different reports	Whether the model uses contextual evidence
Unseen measurement mechanisms	Whether the model generalises beyond familiar patterns

These are proposed evaluation designs. No experimental results are claimed.

### Task B.3 — Generalisation to K hypotheses and continuous outcomes

For (K) competing hypotheses:

\[
H\in\{1,2,\ldots,K\}
\]

Let the prior probability of hypothesis (i) be:

\[
P(H=i)=\pi_i,\qquad
\sum_{i=1}^{K}\pi_i=1
\]

Let the measurement outcome (Y) be continuous, with conditional probability density:

\[
p(y\mid H=i,q)
\]

The marginal outcome density is:

\[
p(y\mid q)=\sum_{i=1}^{K}\pi_i p(y\mid H=i,q)
\]

The information value of question (q) is:

\[
\boxed{
v(q)=I(H;Y\mid q)
=
\sum_{i=1}^{K}\pi_i
\int p(y\mid H=i,q)
\log_2
\frac{p(y\mid H=i,q)}
{p(y\mid q)}
\,dy
}
\]

This is the mutual information between the hidden hypothesis and the continuous measurement outcome, expressed in bits.

What does it mean for a question to be already addressed by the inputs?

Let (R) denote the existing reports. A question is already addressed when the reports provide sufficient evidence to determine the answer, leaving little uncertainty about the relevant hypotheses.

In information-theoretic terms:

\[
H(H\mid R)\approx0
\]

The additional information obtainable from a new measurement, conditioned on the reports, is:

\[
I(H;Y\mid R,q)\leq H(H\mid R)
\]

Therefore, when the existing reports almost completely resolve the hypotheses:

\[
I(H;Y\mid R,q)\approx0
\]

Such a question may still be textually different or interesting, but it contributes little additional information beyond the inputs.

What should a language model output to estimate information value?

For a real research question, a language model should produce:

1. Competing hypotheses: A clearly defined set of hypotheses that the research question aims to distinguish.
2. Prior probabilities: Estimated probabilities for each hypothesis, grounded in the existing reports.
3. Measurement definition: A description of the experiment, observation or measurement proposed by the question.
4. Conditional outcome distributions: Estimated outcome distributions under each competing hypothesis.
5. Evidence and uncertainty: Supporting references, assumptions, limitations and confidence estimates.
6. Information value: An estimated mutual information score, with uncertainty or sensitivity analysis.

These outputs allow the information value to be calculated from explicit probabilistic assumptions rather than guessed from textual similarity.
